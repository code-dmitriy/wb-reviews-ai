# Ответы на отзывы WB с ИИ — прототип на n8n

У многих продавцов на WB на отзывы стоят два шаблона: один на позитив, другой на негатив. Шаблон не видит,
о чём отзыв: «цена завышена» и «не очень удобные» получают «надеемся, станет незаменимой частью
гардероба», а жалоба на штрипки получает «вы не приложили фото». Часть единиц остаётся без ответа.

Прототип пишет ответ под каждый конкретный отзыв, а менеджер одобряет его одной кнопкой в Telegram.

## Как работает

```
Отзывы WB ──► ИИ пишет ответ ──► карточка менеджеру в Telegram
 (API или демо)  + категория      [✅ Опубликовать] [🔄 Переписать]
                 + сигнал команде         │                │
                                          ▼                ▼
                                 ответ уходит в WB    новый вариант
                                 через API            в той же карточке
```

Два воркфлоу в n8n:

1. **Черновики ответов** (`workflows/1_reply_drafts.json`) — берёт неотвеченные отзывы,
   для каждого вызывает LLM и присылает карточку: отзыв, категория (пересорт / брак / размер / цена…),
   черновик ответа и заметка для команды, если нужно что-то проверить на складе.
2. **Кнопки менеджера** (`workflows/2_manager_buttons.json`) — ловит нажатия кнопок.
   «Опубликовать» отправляет ответ в WB, «Переписать» просит модель написать иначе.
   Принимает нажатия только из чата менеджера. Работает через `getUpdates`, поэтому не нужен
   ни публичный сервер, ни вебхук: всё крутится на обычном компьютере.

Режимы (`MODE` в `.env`):
- `demo` — 10 обезличенных демо-отзывов в формате API WB (`data/demo_reviews.json`);
  кнопка «Опубликовать» только помечает карточку.
- `wb` — официальный API продавца: `GET /api/v1/feedbacks?isAnswered=false` и
  `POST /api/v1/feedbacks/answer`. Нужен токен WB с категорией «Вопросы и отзывы».

## Запуск

```bash
cd n8n && npm install && cd ..
cp .env.example .env      # заполнить TG_BOT_TOKEN, TG_CHAT_ID, OPENROUTER_API_KEY
node scripts/start.mjs    # импортирует ключи и воркфлоу, запускает n8n на :5678
```

Дальше откройте http://localhost:5678 → «MIRA · Черновики ответов на отзывы» → Execute workflow.

## Структура

| Файл | Что внутри |
|---|---|
| `prompts/reply_system.md` | правила тона MIRA для модели |
| `src/shared.js` | разбор отзыва, карточка для Telegram, разбор ответа модели |
| `data/demo_reviews.json` | демо-отзывы в формате API WB |
| `build.py` | собирает воркфлоу из промпта, данных и `shared.js` |
| `scripts/start.mjs` | импорт и запуск n8n |

Модель по умолчанию — `google/gemma-4-31b-it:free`, запасная — `nvidia/nemotron-3-ultra-550b-a55b:free` (n8n переключается сам, если основная недоступна). Обе меняются в `.env`.
